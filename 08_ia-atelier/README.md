# IA Atelier

Atelier **responsable** : l’IA comme **levier Data Analyst après maîtrise**, pas comme source de vérité ni comme petit bonus.

## Message clé

- **Impact** : fort, quand le métier est déjà là  
- **Place** : en **dernier** dans la formation  
- **Rôle** : accélérer (SQL, Python, notes…) — jamais remplacer le contrôle humain

## Règle d’or

**Vérifier tout chiffre avant de publier.**

## Contenu

- Quand s’en servir / quand s’en méfier (feu vert · orange · rouge)
- Prompts pour SQL, Excel, Python, storytelling
- Prudence données sensibles (santé, identité)
- Checklist avant publication
- Quiz bilan (seuil 75 %)

## Lancer

1. Ouvrir `index.html`  
   ou : `python -m http.server 8772`
2. Suivre **Parcours**
3. Utiliser **Labo prompts** + **Checklist**

## Place dans le pack

Excel → Stats → Collecte → SQL → Python → Power BI → Storytelling → SIG → Qualité → **IA** → Éthique
