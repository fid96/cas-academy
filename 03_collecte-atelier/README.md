# Collecte Atelier

Première marche du pack **Data Analyst terrain** : collecter proprement (esprit **Kobo / ODK**) pour analyser juste.

## Pourquoi cet atelier ?

Pour un Data Analyst « bureau » classique, la collecte est parfois lointaine.  
Pour un profil **santé / ONG / terrain**, Kobo et la qualité à la source sont **importants**.

## Objectif

- Concevoir un formulaire analysable (name, label, types, required, constraints)
- Préférer les listes au texte libre
- Comprendre le flux Kobo : concevoir → déployer → collecter → exporter
- Brancher l’export sur Excel / SQL / Python / Power BI / Storytelling

## Lancer

1. Ouvrir `index.html`  
   ou : `python -m http.server 8771`
2. Suivre **Parcours**
3. Pratiquer dans **Studio formulaire** (score ≥ 80)
4. Lire **Kobo / ODK**
5. Passer le **Quiz bilan**

## Chaîne complète du pack

**Collecte** → SQL → Excel → Statistiques → Python → Power BI → Storytelling

## Outil réel

Après le Studio pédagogique : [KoboToolbox](https://www.kobotoolbox.org/) (ou serveur de votre organisation).
