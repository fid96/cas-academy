# Storytelling Atelier

Dernière marche du pack **Data Analyst** : transformer KPI et analyses en **note de décision**.

## Finalité

- Cadrer public + décision
- Écrire constat → preuve → limite → recommandation
- Scorer clarté / preuve / prudence / action
- Relier la note à la chaîne SQL → Excel → Stats → Python → Power BI

## Lancer

1. Ouvrir `index.html`  
   ou : `python -m http.server 8770`
2. Suivre **Parcours**
3. Pratiquer dans **Atelier note**
4. Relire **Chaîne DA**
5. Passer le **Quiz bilan**

## Chaîne

Question → SQL → Excel → Statistiques → Python → Power BI → **Storytelling**
